# İngilizce Kelime Oyunu

Tek dosyalı PWA. Güncel sürüm: **V65** (phrasal verb kategorisi dahil).

## Çalıştırma

- `index.html` dosyasını tarayıcıda aç
- veya GitHub Pages: Settings → Pages → Deploy from branch `main` / root

## Cloudflare

`index.html` adıyla Workers/Pages’e yükle. Cache kırmak için `?v=65` kullan.
